# P2-04 — Instagram 소규모 유입 실험

대상: **@jack.made.tools**. 사용자가 P2-04를 승인했고 인스타그램 홍보글/릴스로 방향을 지정했다. 예산은 기존 계획의 **0원**, 최초 게시 후14일 관측한다. 사용자 계정 설정·공개 범위·요금·광고를 변경하지 않는다.

현재: 피드5장·20초 릴스·캡션·추적 링크 준비. **미게시/실험 미시작**이다. Instagram 브라우저 보안 승인에서 사이트 접근이 거절되어 게시·프로필 링크 변경을 하지 않았다. DBeaver 접근도 앱 사용 미승인으로 거절되어 운영 events 행 재조회/DB 시간 저장 전제는 미확인이다. 저장 API202 응답을 DB 행 검증으로 쓰지 않는다.

## 첫 배포물

| 형식 | 내용 | 제작 규격 |
| --- | --- | --- |
| 릴스1개 | 동네 도서관 책 찾기 → 검색 → 지역 도서관 → 공식 사이트 최종 확인 → 프로필 링크 | 1080×1920, 9:16, 30fps, 20초, H.264/AAC 무음 |
| 피드5장 | 같은 메시지를 넘겨 보는 정보형 캐러셀 | 1080×1350 PNG, 01→05 순서 |
| 캡션2개 | 개발자가 직접 운영한다는 소개·실제 기능·한계·피드백 요청 | [문안](instagram-p2-04/captions.md) |

실제 운영 지역 화면을 포함했고 가상의 성공 후기/사용자 수/대출 성공 사례를 넣지 않았다. 예약 자동화·실시간 보장·전국 모든 도서관 보장·보류 중인 알림 기능은 홍보하지 않는다. 음악은 포함하지 않으며 실제 앱에서 음악을 붙일 경우 게시 계정에서 사용할 수 있는 곡인지 별도로 확인한다.

## 측정 링크와 귀속

- 프로필: `https://www.near-book.com/?source=instagram-bio-p204-20261020`
- 스토리 링크: `https://www.near-book.com/?source=instagram-story-p204-20261020`
- 자체 검증은 `source=qa-p204-20261020`으로 분리한다. 위 실험 source를 QA 방문에 쓰지 않는다.

피드와 릴스가 같은 프로필 링크를 쓰므로 웹 전환은 인스타 프로필 유입 합계다. 게시물별 웹 전환이나 인과 효과로 해석하지 않는다. 각 게시물의 조회/도달/저장/프로필 방문 등은 **계정에서 실제 제공되는 Instagram 지표만** 기록한다. 제공되지 않는 지표는 빈칸/미측정으로 남긴다. 이를 위해 프로 계정 전환이나 공개 범위 변경을 하지 않는다. 스토리 링크가 제공될 때만 별도 source로 웹 유입을 구분한다.

## 시작 전 확인

1. 정확한 계정이 @jack.made.tools인지, 게시와 프로필 링크 추가가 가능한지 확인한다. 현재 접근 거절이 있어 미확인이다. 다른 브라우저/API/우회 수단으로 대체하지 않는다.
2. 프로필 링크를 실제 추가하고 기존 링크/소개를 보존한 상태에서 열림을 확인한다. 이후에 프로필 링크 CTA를 게시한다.
3. 운영 events 실제 저장 행에서 v2 visit·search_submit·book_detail_view·holdings_request_completed·library_click의 수집을 확인한다. 응답202와 실제 저장은 구분한다. 집계 전 DB timestamp 저장 기준을 [사전 쿼리](instagram-p2-04/readiness.sql)로 확인한다.
4. 결과가 unknown인 보유 조회를 ‘확인 완료’로 세지 않는지 확인한다. 공급자 예산500/일을 변경하거나 홍보 목적으로 강제 갱신하지 않는다.
5. 최초 실제 게시의 permalink와 UTC 시각을 results.csv에 기록한다. 그 시점이 D0이며 파일 제작일/승인일은 실험 시작일이 아니다.

## 성과 정의

핵심 지표: 방문 이후 같은 책의 `holdings_request_completed`가 complete/partial이고 `checkedCount > 0`인 세션 수. 이는 상태 확인이며 소장·대출 가능·실제 대출 성공 수가 아니다. `library_status_view`만으로 성공을 집계하지 않는다.

보조 지표: visit→유효 검색 제출→같은 query 책 선택→같은 ISBN 상세→상태 확인→requestId가 연결된 공식 사이트/길찾기 클릭. 찜·구매·알림 설정을 필수 성과로 삼지 않는다. 정상 결과0건과 pending/오류를 나누고 unknown·조회 실패·오래된 상태 비율을 함께 본다.

7일 내 다른 세션 재방문과 D7 [7일,8일) 재방문은 별개다. 브라우저/탭/수집 실패의 한계가 있으며 사람 수나 신규 가입자 수가 아니다. 새 캠페인 유입 코호트와 기존 전체 사용자 코호트도 구분한다.

## 관측 일정

- D0: 계측 확인·프로필 링크·릴스1개 게시, 실제 링크/시각 기록.
- D3: 댓글과 오류를 검토하고 중대한 문제가 없으면 피드 캐러셀1개 추가.
- D5: 계정에서 링크 스티커를 제공하면 스토리1개로 별도 유입 관측.
- D7: 중간 점검. 미성숙 코호트의7일 재방문을0%로 표시하지 않는다.
- D14: 방문·검색·상태 확인·공식 사이트 클릭·반복 피드백의 중간 결론. 마지막 유입의7일 관측은 아직 끝나지 않았음을 명시한다.
- D22 이후: 마지막 캠페인 유입의 D7 관측까지 성숙한 뒤 재방문 최종 비교.

임계값은 가설이다. 예를 들어 방문50세션 미만이면 비율만으로 확대 결론을 내리지 않는다. 측정 누락/반복 오류·정확도 불만은 먼저 수정한다. 원시 수치·분모·기간·피드백을 함께 보고 다음 채널/문구 변경을 결정한다. 방문자 수만으로 성공 처리하지 않는다.

## 실행 기록

[results.csv](instagram-p2-04/results.csv)는 빈 측정 템플릿이다. 미측정을0건으로 쓰지 않는다. 운영 수집 확인과 실제 게시/관측 결과가 없으므로 KAN-123은 진행 중이며 완료하지 않는다.

제작물은 `nearbook-instagram-p2-04-20261020/` 폴더에 있다. 생성기는 `scripts/marketing/render-instagram.py`. 선택 도구 Pillow/imageio-ffmpeg는 임시 제작 환경에만 설치했고 제품/lockfile/서버에는 추가하지 않았다. 공개 지역 화면의 스크린샷만 사용했다.

형식 참고: [Meta Reels 안내](https://www.facebook.com/business/ads/facebook-instagram-reels-ads)의 세로9:16 제작 방향을 참고했다. Help Center 상세 규격 페이지는429로 읽지 못했으므로 계정별 최신 업로드 허용 범위를 확인했다고 주장하지 않는다. 실제 업로드 시 인스타 미리보기와 잘림을 확인한다.
