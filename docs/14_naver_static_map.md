# 14 — Naver Static Map

## 작업
도서관 위치를 정적 이미지로 표시한다.

> **사용 범위**: Static Map은 도서관 상세 페이지(`/library/[id]`)의 단일 좌표 미리보기에만 사용한다.
> 다중 마커가 필요한 `/libraries` 리스트와 홈 "내 주변 도서관"은
> **/libraries에 이미 존재하는 Web Dynamic Map 컴포넌트를 재사용**한다 — 신규 컴포넌트 추가 금지.

## 변경 이력
- 2026-05-03: 사용 범위를 도서관 상세 단일 좌표로 한정. 다중 마커 지도는 /libraries 기존 컴포넌트 재사용으로 통일. dynamic-map 신규 추가 시도는 롤백.
